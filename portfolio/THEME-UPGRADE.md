# Portfolio Theme & Animation Upgrade

This branch contains the professional Angular 21 portfolio visual refresh prepared for Rangaprasad R.

Highlights:
- Light, Dark and Midnight themes
- Animated hero architecture visual
- Scroll reveal and staggered cards
- Scroll progress indicator
- Glassmorphism navigation on scroll
- Hover/focus micro-interactions
- GitHub repository loading skeletons
- Reduced-motion accessibility support

The packaged implementation is available separately as the Angular portfolio project.
